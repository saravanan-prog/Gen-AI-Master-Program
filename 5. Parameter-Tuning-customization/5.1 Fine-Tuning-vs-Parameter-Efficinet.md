## Fine-tuning vs. Parameter-Efficient Fine-Tuning (LoRA, PEFT, Adapters)

### 1. Fine-tuning

***Fine-tuning*** means training an already-trained AI model again using **our own dataset** for a **specific task**.

***Example***: Train an existing AI model using medical data to answer medical questions.

```
Pre-trained Model
       |
       v
  Custom Dataset
       |
       v
   Fine-tuning
       |
       v
 Specialized AI Model

 ```

 ### 2. PEFT (Parameter-Efficient Fine-Tuning)

 ***PEFT*** (Parameter-Efficient Fine-Tuning) is a method that trains only a small part of the AI model instead of ***changing all its parameters***.

 ***Why do we need PEFT*** - A large AI model may contain billions of parameters.

 Training all parameters can require:

 - More GPU memory
 - More training time
 - More computing cost

***PEFT*** helps us train the model with ***fewer resources***.

### 3. LoRA :-

**LoRA** is a ***PEFT technique*** that adds `small trainable matrices` to `selected layers` of an ***existing AI model***.

***Example***
```
magine a model has 100 million parameters.
    - Full fine-tuning may train all 100 million parameters.
    - LoRA may train only a small part of the parameters.
```
***Important***: LoRA is a method. `PEFT` is the `library/framework` that helps us use methods like `LoRA`.

 ### 4. Adapters :-

 ***Adapters*** are small `trainable components` added to an **existing AI model to customize it for a new task.**

 - We have one base AI model.
 -We want to use it for three tasks:

 ```
                 Base AI Model
                     |
          +----------+----------+
          |          |          |
          v          v          v
      Adapter 1  Adapter 2  Adapter 3
       Support    Coding     Finance
          |          |          |
          v          v          v
      Support AI  Coding AI  Finance AI
 ```
***Relationship between LoRA, PEFT and Adapters***

 | Name             | Meaning                                              |
| ---------------- | ---------------------------------------------------- |
| Fine-tuning      | Training an existing model again                     |
| Full fine-tuning | Training all or nearly all model parameters          |
| PEFT             | Training a small number of parameters                |
| LoRA             | A popular PEFT method                                |
| Adapters         | Small trainable components used to customize a model |

```
from datasets import Dataset
from transformers import (
    AutoTokenizer,
    AutoModelForCausalLM,
    Trainer,
    TrainingArguments,
    DataCollatorForLanguageModeling
)
from peft import LoraConfig, get_peft_model, TaskType

# 1. Load a small pre-trained model
model_name = "sshleifer/tiny-gpt2"

tokenizer = AutoTokenizer.from_pretrained(model_name)

tokenizer.pad_token = tokenizer.eos_token

model = AutoModelForCausalLM.from_pretrained(model_name)

# 2. Create simple training data
data = {
    "text": [
        "Question: What is our company name?\nAnswer: Sunaina Technologies.",
        "Question: What do we teach?\nAnswer: Software development and GenAI.",
        "Question: Which language do we teach?\nAnswer: Python and Java.",
        "Question: What is GenAI?\nAnswer: GenAI creates new content."
    ]
}

dataset = Dataset.from_dict(data)

# 3. Convert text into tokens
def tokenize_data(example):
    return tokenizer(
        example["text"],
        truncation=True,
        max_length=64
    )

tokenized_dataset = dataset.map(
    tokenize_data,
    remove_columns=["text"]
)

# 4. Configure LoRA
lora_config = LoraConfig(
    task_type=TaskType.CAUSAL_LM,
    r=4,
    lora_alpha=8,
    lora_dropout=0.1,
    target_modules=["c_attn"]
)

# 5. Apply LoRA to the model
model = get_peft_model(model, lora_config)

# 6. Check trainable parameters
model.print_trainable_parameters()

# 7. Configure training
training_args = TrainingArguments(
    output_dir="./lora-output",
    per_device_train_batch_size=2,
    num_train_epochs=3,
    save_strategy="no",
    report_to="none"
)

# 8. Prepare training
trainer = Trainer(
    model=model,
    args=training_args,
    train_dataset=tokenized_dataset,
    data_collator=DataCollatorForLanguageModeling(
        tokenizer=tokenizer,
        mlm=False
    )
)

# 9. Start training
trainer.train()

# 10. Save the LoRA adapter
model.save_pretrained("./company-lora")

print("LoRA training completed!")

```
