#  Adding Data to a List

## `append()`

`append()` adds one item to the end.

```python
students = ["Arun", "Priya"]

students.append("Ravi")

print(students)      
```

Output:

```text
['Arun', 'Priya', 'Ravi']
```

---

## `insert()`

`insert()` adds an item at a specific position.

```python
students = ["Arun", "Ravi","Parvathi","Raja"]

students.insert(1, "Priya")

print(students)
```

Output:

```text
['Arun', 'Priya', 'Ravi',"Parvathi","Raja"]
```

---

## `extend()`

`extend()` adds multiple items.

```python

engineeringStudents = ["Arun", "Priya"]
artsStudents = ["Ravi", "Kumar"]

engineeringStudents.extend(artsStudents)

print(engineeringStudents)
```

Output:

```text
['Arun', 'Priya', 'Ravi', 'Kumar']
```
