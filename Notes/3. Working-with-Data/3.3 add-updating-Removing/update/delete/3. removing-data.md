# 12. Removing Data

## `remove()`

Removes a specific value.

```python
students = ["Arun", "Priya", "Ravi"]

students.remove("Priya")

print(students)
```

Output:

```text
['Arun', 'Ravi']
```

---

## `pop()`

Removes an item using its index.

```python
students = ["Arun", "Priya", "Ravi"]

students.pop(1)

print(students)
```

Output:

```text
['Arun', 'Ravi']
```

If we don't give an index:

```python
students.pop()
```

It removes the last item.

---

## `del`

We can also use `del`.

```python
students = ["Arun", "Priya", "Ravi"]

del students[1]

print(students)
```

Output:

```text
['Arun', 'Ravi']
```
