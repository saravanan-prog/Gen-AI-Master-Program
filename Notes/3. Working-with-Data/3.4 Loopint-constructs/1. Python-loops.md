# Python Looping

A loop is used when we want to repeat something.

For example, instead of writing:

```python
print("Arun")
print("Priya")
print("Ravi")
```

we can use a loop.

`for` and `while`

| `for`                           | `while`                                |
| ------------------------------- | -------------------------------------- |
| Used to go through a collection | Used while a condition is true         |
| Easy for lists                  | Good when condition controls the loop  |
| Commonly used with lists        | Commonly used with counters/conditions |

Example:

```python
for student in students:
    print(student)
```

Use `for` when you want to process each item.

Example:

```python
count = 1

while count <= 5:
    print(count)
    count += 1
```

Use `while` when a condition controls how long the loop runs.
