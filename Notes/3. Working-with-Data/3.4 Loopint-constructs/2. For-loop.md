#  `for` Loop

The `for` loop is commonly used to go through a collection.

```python
students = ["Arun", "Priya", "Ravi"]

for student in students:
    print(student)
```

Output:

```text
Arun
Priya
Ravi
```

### How it works

```text
students
   ↓
Arun → print
   ↓
Priya → print
   ↓
Ravi → print
```

The loop takes one item at a time.

# 15. `for` Loop with Numbers

```python
numbers = [10, 20, 30, 40]

for number in numbers:
    print(number)
```

Output:

```text
10
20
30
40
```
