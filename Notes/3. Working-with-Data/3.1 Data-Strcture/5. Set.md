# 5. Set

## What is a Set?

A **Set** stores unique values.

It automatically removes duplicate values.

```python
numbers = {10, 20, 10, 30, 20}

print(numbers)
```

Output:

```text
{10, 20, 30}
```

The duplicate values are removed.

### Important

A set does not maintain data in a normal index-based order.

So we generally do not access set values like this:

```python
numbers[0]
```
