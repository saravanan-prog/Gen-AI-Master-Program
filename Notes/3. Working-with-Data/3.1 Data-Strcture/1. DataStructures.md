# Python Data Structures

## What is a Data Structure?

A **data structure** is a way to store and organize data in a program.

For example, suppose we have 5 student names:

```python
"Arun"
"Priya"
"Ravi"
"Meena"
"Kumar"
```

Instead of creating 5 separate variables, we can store them together:

```python
students = ["Arun", "Priya", "Ravi", "Meena", "Kumar"]
```

Here, `students` is a **List**.

Python provides four important data structures:



| Data Structure | Syntax         | Duplicate Values    | Can Change? |
| -------------- | -------------- | ------------------- | ----------- |
| List           | `[]`           | Yes                 | Yes         |
| Tuple          | `()`           | Yes                 | No          |
| Dictionary     | `{key: value}` | Keys must be unique | Yes         |
| Set            | `{}`           | No                  | Yes         |

### Easy memory trick

```text
List       → Collection of values
Tuple      → Fixed collection
Dictionary → Key + Value
Set        → Unique values
```
