# Tuple

## What is a Tuple?

A **Tuple** is similar to a list, but we normally use it when the data should not be changed.

```python
student = ("Arun", 25, "Chennai")

print(student)
```

Output:

```text
('Arun', 25, 'Chennai')
```

### Tuple cannot be changed

```python
student = ("Arun", 25, "Chennai")

student[1] = 30
```

This will give an error because tuples cannot be modified.

---

## List vs Tuple

| List                   | Tuple               |
| ---------------------- | ------------------- |
| `[]`                   | `()`                |
| Can be changed         | Cannot be changed   |
| Mutable                | Immutable           |
| Good for changing data | Good for fixed data |

Example:

```python
students = ["Arun", "Priya"]
```

Use a list when the data may change.

```python
location = ("Chennai", "Tamil Nadu")
```

Use a tuple when the data should remain fixed.
