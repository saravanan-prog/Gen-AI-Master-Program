# 4. Dictionary

## What is a Dictionary?

A **Dictionary** stores data using:

```text
Key : Value
```

Example:

```python
student = {
    "name": "Arun",
    "age": 22,
    "city": "Chennai"
}

print(student)
```

Output:

```text
{'name': 'Arun', 'age': 22, 'city': 'Chennai'}
```

Think of it like a real dictionary:

```text
name → Arun
age  → 22
city → Chennai
```

---

## Access Dictionary Data

We can use the key:

```python
student = {
    "name": "Arun",
    "age": 22
}

print(student["name"])
```

Output:

```text
Arun
```

Another example:

```python
print(student["age"])
```

Output:

```text
22
```
