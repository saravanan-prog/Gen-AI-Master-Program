#  List

## What is a List?

A **List** stores multiple values in a single variable.

### Example

```python
students = ["Arun", "Priya", "Ravi"]

print(students)
```

Output:

```text
['Arun', 'Priya', 'Ravi']
```

A list can contain different types of data:

```python
data = ["Arun", 25, 10.5, True]

print(data)
```

---

## List Allows Duplicates

```python
numbers = [10, 20, 10, 30, 20]

print(numbers)
```

Output:

```text
[10, 20, 10, 30, 20]
```

The same value can appear multiple times.

---

## List is Mutable

**Mutable** means we can change the data after creating the list.

```python
students = ["Arun", "Priya", "Ravi"]

students[1] = "Kumar"

print(students)
```

Output:

```text
['Arun', 'Kumar', 'Ravi']
```
