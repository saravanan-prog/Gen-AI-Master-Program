# 9. Slicing

## What is Slicing?

Slicing means taking a part of a list.

Syntax:

```python
list[start:end]
```

Example:

```python
students = ["Arun", "Priya", "Ravi", "Kumar", "Meena"]

print(students[1:4])
```

Output:

```text
['Priya', 'Ravi', 'Kumar']
```

Important:

> The `end` index is not included.

```text
students[1:4]

Index:     0       1       2       3       4
Value:   Arun    Priya    Ravi    Kumar   Meena
                   ↑       ↑       ↑
                 Start             End
```

Index `4` is not included.

---

## Slice from Beginning

```python
students = ["Arun", "Priya", "Ravi", "Kumar"]

print(students[:2])
```

Output:

```text
['Arun', 'Priya']
```

---

## Slice Until the End

```python
print(students[2:])
```

Output:

```text
['Ravi', 'Kumar']
```
