# 1. Indexing

## What is Indexing?

Indexing means accessing a particular item using its position.

Important:

> Python index starts from `0`.

Example:

```python
students = ["Arun", "Priya", "Ravi"]
```

The positions are:

```text
Value       Arun      Priya      Ravi
Index         0         1          2
```

So:

```python
print(students[0])
```

Output:

```text
Arun
```

```python
print(students[1])
```

Output:

```text
Priya
```

```python
print(students[2])
```

Output:

```text
Ravi
```

---

# 2. Negative Indexing

Python also supports negative indexes.

```text
Value       Arun      Priya      Ravi
Index         0         1          2
Negative     -3        -2         -1
```

Example:

```python
students = ["Arun", "Priya", "Ravi"]

print(students[-1])
```

Output:

```text
Ravi
```

`-1` means the **last item**.
