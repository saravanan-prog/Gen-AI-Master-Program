# 3.2 What is a Token?

A token is a `small unit of text` processed by a `language model`.

For example:

```
    "Hello world"
    "I love Python"
    "who is saravanan"
```
may be split into tokens.

```
    ["Hello" , "world"]
        1000     1004

    ["I", "love", "Python"]
      2525 4585    6545


    ["who", "is", "saravanan"] 
       
                       ↓
                    "sara","vanan"
                       ↓
                    "sa","ra","va","na","n"
```

A token can be:

* A complete word
* Part of a word
* Punctuation
* A special symbol

### Why are tokens important?

LLMs process text as tokens.

```
            Text
              ↓
            Tokens
              ↓
            Model
              ↓
            Output Tokens
              ↓
            Text
```

### Example
```
        "I love Python"
            ↓
        Tokenization
            ↓
        ["I", "love", "Python"]
            ↓
        [40, 982, 15243]
            ↓
            LLM
```
