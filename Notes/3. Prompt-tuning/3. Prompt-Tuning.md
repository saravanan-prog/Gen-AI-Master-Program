#  Prompt Tuning for AI Models

Improving your prompt so the AI gives a more `accurate`, `useful`, `consistent`, or `creative` response.

Think about a normal prompt:
```
    Explain JavaScript.

```
This is too general.

We can gradually improve it:
```
    Explain JavaScript functions.
```
Then:
```
    Explain JavaScript functions to a beginner.
```
Then
```
    Explain JavaScript functions to a beginner.

    Use:
    - Simple English
    - One real-world example
    - One small code example
    - Explain the output
```
