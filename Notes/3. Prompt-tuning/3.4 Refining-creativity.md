# Refining Prompts for Creativity

Accuracy and creativity are different goals.

Suppose you ask:
```
    Give me ideas for a JavaScript project.
```
You might get generic answers.

Instead:
```
Give me 10 creative JavaScript project ideas

for college students.

The projects should:
    - Be practical
    - Be possible without a backend
    - Use HTML, CSS and JavaScript
    - Be different from common calculator/todo apps

Give a one-line description for each.
```

Now you've directed the creativity.

### Important idea

For creative tasks, you can specify:
```
    Audience
    Style
    Number of ideas
    Constraints
    Format
```
