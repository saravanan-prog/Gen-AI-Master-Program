##  Refining — Accuracy
------------------------------------------------------------------------

Let's start with a weak prompt.

```
    Tell me about Java.
```
Possible problem:

- Too broad
- Audience not specified
- No desired format
- No scope

### Improve it

```
    Explain Java to a beginner.
```
Result : `Better`.

### Improve again

```
Explain Java to a beginner developer.

Cover:
    1. What Java is
    2. Why Java is used
    3. Java vs Python
    4. One real-world example

Use simple English.

```
Result : `Now the AI has clear boundaries.`

### Improve further
```
You are a Java trainer.

Explain Java to a student who has
basic programming knowledge but has never
used Java.

Cover:
    1. What Java is
    2. Why Java is used
    3. JDK vs JRE vs JVM
    4. Real-world example

Use simple English.
Give one Java code example.
Explain the expected output.

Avoid advanced Java topics such as
Spring Boot, multithreading, and microservices.

```
