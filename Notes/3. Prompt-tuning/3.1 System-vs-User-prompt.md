
#  System Prompt vs User Prompt

## System Prompt

A system `instruction establishes high-level behavior`, rules, or context
for the AI.

```
        SYSTEM  → General instructions / behavior
        USER    → Specific task
```


Example : `SYSTEM PROMPT `

```
You are a Python trainer.

Your teaching rules:
- Explain concepts for beginners.
- Use simple English.
- Give real-world examples.
- Give small code examples.
- Avoid advanced concepts unless requested.
```

Then : `USER PROMPT`


```
    Explain Python functions.

    Please include:
        1. Simple definition
        2. Real-world example
        3. Small JavaScript example
        4. Expected output

```
