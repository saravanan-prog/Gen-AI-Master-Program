# Refining Prompts for Consistency

This is especially useful in `software applications`.

Suppose you repeatedly ask:
```
    Explain React.
```
Then 

```
    Explain Python.
```
Then
```
    Explain Docker.
```
The output format may change every time.

Instead:
```
    Explain React concepts using this format:

        Definition:
        Real-world example:
        Simple code:
        Output:
        Key takeaway:

        Now every answer has a predictable structure.

```
