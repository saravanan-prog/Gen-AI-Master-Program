# Refining Prompts

A first prompt is often not the final prompt.

### Version 1

``` text
    Explain Python.
```

### Version 2

``` text
    Explain Python to a beginner.
```

### Version 3

``` text

    Explain Python to a beginner.

    Cover:
        - Variables
        - Data types
        - Functions
        - Lists

    Use simple examples.
```

### Version 4

``` text
    You are a Python trainer teaching freshers.

    Explain Python fundamentals.

    Cover:
        1. Variables
        2. Data types
        3. Functions
        4. Lists

    For each topic provide:
        - Simple definition
        - Real-world example
        - Small code example

    Avoid advanced topics.
```

### Lesson

``` 
            Vague Prompt
                ↓
            Add Audience
                ↓
            Add Context
                ↓
            Add Constraints
                ↓
            Add Output Format
                ↓
            Better Response
```
