# MCP Architecture
MCP provides a standard way for an `AI application to communicate` with `external systems`.

External systems can be:
- APIs
- Databases
- Files
- Tools
- Business applications



The three important components are:

**Host** -  The Host is `the application where the AI` is running.

**Client** -  The `MCP Client` is the `component that communicates` with the `MCP Server`.

**Server** - The `MCP Server` provides access to `external capabilities`.
