## JSON Object → Python Dictionary

JSON :
```

    student = '{"name": "Ravi", "age": 25, "city": "Chennai"}'
 ```       
Python equivalent: Dictionary
```
    student = {
        "name": "Ravi",
        "age": 25
    }
    print(student["name"])
```

### Convert Python dictionary → JSON
Python provides the json module.
```
import json
```
Convert Python dictionary → JSON
```
    import json

    student = {
        "name": "Ravi",
        "age": 25
    }

    json_data = json.dumps(student)      # Convert dictionary data into JSON format.

    print(json_data)

```

Convert JSON → dictionary

```
    import json

    json_data = '{"name": "Ravi", "age": 25}'

    student = json.loads(json_data)              # Convert JSON data into dictionary format.      

    print(student["name"])

```
