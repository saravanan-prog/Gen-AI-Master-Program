# 1. What is a Dataset?

A dataset is simply a collection of data.

```
    Python-training/
        │
        ├── students.csv
        └── dataset.py


```

Example : **students.csv**
| Name  | Age | Course |
| ----- | --: | ------ |
| Arun  |  22 | Python |
| Kumar |  24 | Java   |
| Priya |  23 | AI     |


### Load CSV Dataset
- **pandas** is a Python library used to work with data.
- read_csv() reads the CSV file.
- The data is stored inside a DataFrame."


Install Pandas

```
    pip install pandas
```

Now dataset.py:

```
    import pandas as pd

    data = pd.read_csv("students.csv")

    print(data)
```

## See Dataset Information

**print( data.head() )** - This displays the first rows.

**print(data.shape)** - Print the data shape row and column

**print(data.columns)** - We are getting  the name column.

**print(data["name"])** - Access One Column


### Access One Row

```
    print(data.iloc[0])
```

Example
```
    import pandas as pd

    data = pd.DataFrame({
        "name": ["Arun", "Kumar", "Priya"],
        "age": [22, 24, 23]
    })

    print(data.iloc[0])                      // iloc = position-based selection
    print(data.iloc[1])
    print(data.iloc[0, 0])                  //Output : Arun

```

### Add New Data

Example : **students.csv**
| Name  | Age | Course |
| ----- | --: | ------ |
| Arun  |  22 | Python |
| Kumar |  24 | Java   |
| Priya |  23 | AI     |

```
    import pandas as pd

    data = pd.read_csv("students.csv")
    
    data["status"] = "Active"
    print(data)

Output:
    name  age  course  status
0   Arun   22  Python  Active
1  Kumar   24   Java   Active
2  Priya   23    AI    Active
```

# Change Existing Data

```
    import pandas as pd

    data = pd.read_csv("students.csv")
    data.loc[0, "course"] = "AI"
    print(data)


Output:

    name  age course  status
0   Arun   22     AI  Active
1  Kumar   24   Java  Active
2  Priya   23     AI  Active
```

## Save the Dataset
```
    import pandas as pd

    data = pd.read_csv("students.csv")
    data["status"] = "Active"

    data.loc[0, "course"] = "AI"
    print(data)
    data.to_csv("students_updated.csv", index=False)



output:
    Python-training/
        │
        ├── students.csv
```
