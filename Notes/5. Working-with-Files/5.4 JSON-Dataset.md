# JSON Dataset

JSON is also very important because APIs commonly use JSON.

Create: students.json

```
[
    {
        "name": "Arun",
        "age": 22,
        "course": "Python"
    },
    {
        "name": "Kumar",
        "age": 24,
        "course": "Java"
    }
]
```

## Load JSON
```
import json

with open("students.json", "r") as file:
    data = json.load(file)

print(data)

Output:

[
    {'name': 'Arun', 'age': 22, 'course': 'Python'},
    {'name': 'Kumar', 'age': 24, 'course': 'Java'}
]
```

## Save JSON

```
import json

with open("students.json", "r") as file:
    data = json.load(file)

data.append({
    "name": "Priya",
    "age": 23,
    "course": "AI"
})


with open("students_updated.json", "w") as file:
    json.dump(data, file, indent=4)
```
