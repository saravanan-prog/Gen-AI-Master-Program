# Marketing Copy

Marketing copy = words used to promote a product/service.

For example, imagine we have a training course.

Basic prompt
```
    Write marketing content for a Python course.
```
This is too general.

Better prompt
```
You are a marketing copywriter.

Create promotional content for a Python training course.

Target audience:
- College students
- Fresh graduates

Course features:
- Python fundamentals
- Practical exercises
- Real-world projects
- Beginner-friendly training

Create:
1. Headline
2. Short description
3. 3 key benefits
4. Call to action

Use simple and engaging English.
```

Now AI knows:
```
    WHO?       → Marketing copywriter
    PRODUCT?   → Python course
    AUDIENCE?  → Students/freshers
    CONTENT?   → Headline + benefits + CTA
    STYLE?     → Simple and engaging

```
