# Brainstorming 💡

**Brainstorming** = generating many ideas before choosing what to work on.

For example, a company wants to create a new software product.

Simple prompt
```
    Give me some software project ideas.
```
Too broad.

Better prompt
```
We want to build a software product for college students.

Generate 10 project ideas.

Requirements:
- Solve a real student problem
- Should be possible as a web application
- Should use AI where useful
- Should be suitable for a small development team

For each idea provide:
1. Project name
2. Problem it solves
3. Main feature

Now AI is being used as a brainstorming partner.
```
