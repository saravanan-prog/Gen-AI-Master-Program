# Introduction to MCP

## Model Context Protocol (MCP)

**MCP = Model Context Protocol**

> MCP is a standard way for an AI application to connect with external tools, databases, APIs, and other data sources.

In simple words:

```text
MCP = A standard connection between AI and external tools
```

### Why do we need MCP?

- An AI model can generate text and answer questions,
-  but it may need external systems to get current information or perform actions.

For example:

```text
                  AI
                  ↓
            "I need current customer information."
                  ↓
            Customer Database
```

The AI needs a way to communicate with that database.

MCP provides a standard approach for this type of connection.

# 2. Importance of Standardizing LLM-to-Tool Connections

First, understand the word **standardizing**.

### What does standardizing mean?

Standardizing means:

> Using a common method or common rules.

### Simple Real-Life Example

Imagine every mobile phone used a completely different charging connector.

```text
Phone A → Charger A
Phone B → Charger B
Phone C → Charger C
Phone D → Charger D
```

It would be difficult to manage.

A common standard makes connections easier.

```text
Common Standard
      ↓
Many Devices
      ↓
Easy Connection
```

MCP applies a similar idea to AI and tools.
