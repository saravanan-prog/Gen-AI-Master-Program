# 2. Importance of Standardizing LLM-to-Tool Connections

First, understand the word **standardizing**.

### What does standardizing mean?

Standardizing means:

> Using a common method or common rules.

### Simple Real-Life Example

Imagine every mobile phone used a completely different charging connector.

```text
Phone A → Charger A
Phone B → Charger B
Phone C → Charger C
Phone D → Charger D
```

It would be difficult to manage.

A common standard makes connections easier.

```text
Common Standard
      ↓
Many Devices
      ↓
Easy Connection
```

MCP applies a similar idea to AI and tools.
