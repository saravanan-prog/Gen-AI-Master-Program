

##  Anatomy of a Prompt

A simple prompt has 5 main parts
```
    ROLE
     +
    TASK
     +
    CONTEXT
     +
    CONSTRAINTS
     +
    OUTPUT FORMAT
```

**Role:** - Respond from the `perspective`

**Task:** - This is the `actual work` you want `AI to perform`.

**Context:** - Context gives `background information`

**Constraints:** -  tell AI what `limitations` or `rules` to follow.

**Output-Format:** - This tells AI `how you want the response` to look.



### Example

```
Role:
   You are a JavaScript trainer.

Task:
  Explain JavaScript functions.

Context:
   The students are beginners and know basic HTML and CSS.

Constraints:
    Use simple English.
    Give only one simple example.

Output Format:
    Give the answer with:
    1. Definition
    2. Syntax
    3. Example
    4. Practice question

```
