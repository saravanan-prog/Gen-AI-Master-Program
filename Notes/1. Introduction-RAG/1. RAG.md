# What is RAG?

RAG = **Retrieval-Augmented Generation**

RAG allows an AI model to **find information from an external source** and use that information to answer a question.

An LLM may know **general information**, but **it may not know your private or specific information**

# External Knowledge Base
> A knowledge base is a collection of information that the AI can search.
- PDF
- Word document
- Text file
- Website
- Database
- Company documents
- Product documents

Example
```
    Company HR Policy
    College Rules
    Product Manual
    Private PDF
    Internal Database

```
Suppose we have a college document:

**college.txt**
```

ABC College

College working time: 9 AM to 4 PM
Library working time: 9 AM to 6 PM
Principal: Dr. Kumar
```  

Student asks:
```
What is the library working time?
```
RAG finds: **college.txt**
```
    Library working time: 9 AM to 6 PM
```

Then the AI gives:
```
    The library working time is 9 AM to 6 PM.
```
