#  Python Data Types

A **data type** tells us what kind of value we are storing.

For this lesson, we will learn four important data types:



| Data Type | Meaning        | Example  |
| --------- | -------------- | -------- |
| String    | Text           | `"Arun"` |
| Integer   | Whole number   | `25`     |
| Float     | Decimal number | `25.5`   |
| Boolean   | True or False  | `True`   |





---

#  String

A **string** is text.

We normally write a string inside quotes.

### Example

```python
name = "Arun"
course = "Generative AI"
city = "Chennai"
```

Here:

```text
name   → String
course → String
city   → String
```

### Check the data type

Python provides the `type()` function.

```python
name = "Arun"

print(type(name))
```

Output:

```text
<class 'str'>
```

`str` means **string**.

---

#  Integer

An **integer** is a whole number.

Examples:

```python
age = 25
students = 50
mark = 90
```

There is no decimal point.

```text
25
50
90
```

### Example

```python
age = 25

print(age)
print(type(age))
```

Output:

```text
25
<class 'int'>
```

`int` means **integer**.

---

#  Float

A **float** is a number with a decimal value.

Examples:

```python
price = 99.50
height = 5.8
percentage = 85.5
```

### Example

```python
price = 99.50

print(price)
print(type(price))
```

Output:

```text
99.5
<class 'float'>
```

---

#  Boolean

A **boolean** has only two values:

```text
True
False
```

Boolean values are useful when something has only two possible states.

### Example

```python
is_student = True
is_completed = False
```

### Check the type

```python
is_student = True

print(is_student)
print(type(is_student))
```

Output:

```text
True
<class 'bool'>
```

`bool` means **boolean**.



# Practical Example – Student Information

```python
student_name = "Arun"

is_passed = True

print(student_name)
```

Output:

