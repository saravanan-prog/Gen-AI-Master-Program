#  Output – `print()`

The `print()` function displays information on the screen.

### Simple Example

```python
print("Hello Python")
```

Output:

```text
Hello Python
```

### Print a variable

```python
name = "Arun"

print(name)
```

Output:

```text
Arun
```

### Print multiple values

```python
name = "Arun"
age = 22

print(name, age)
```

Output:

```text
Arun 22
```

---

#  Practical `print()` Example

```python
name = "Arun"
course = "Generative AI"
age = 22

print("Name:", name)
print("Course:", course)
print("Age:", age)
```

Output:

```text
Name: Arun
Course: Generative AI
Age: 22
```

#  Input – `input()`

The `input()` function is used to get information from the user.

### Example

```python
name = input("Enter your name: ")

print("Hello", name)
```

When the program runs:

```text
Enter your name: Arun
```

Output:

```text
Hello Arun
```

### Flow

```text
        User
         ↓
        input()
         ↓
        Python Program
         ↓
        print()
         ↓
        Output
```

---

# Important Point About `input()`

By default, `input()` returns a **string**.

Example:

```python
age = input("Enter your age: ")

print(type(age))
```

If the user enters:

```text
25
```

Output:

```text
<class 'str'>
```

Even though the user entered `25`, Python receives it as text.

---

#  Convert Input to Integer

If we need a number, we can use `int()`.

```python
age = int(input("Enter your age: "))

print(age)
print(type(age))
```

If the user enters:

```text
25
```

Output:

```text
25
<class 'int'>
```

---

#  Convert Input to Float

Use `float()` when we need a decimal number.

```python
price = float(input("Enter product price: "))

print(price)
```

If the user enters:

```text
99.50
```

Output:

```text
99.5
```

#  Practical Example – Simple Calculator

Let's create a small calculator.

```python
a = int(input("Enter first number: "))
b = int(input("Enter second number: "))

addition = a + b
subtraction = a - b
multiplication = a * b

print("Addition:", addition)
print("Subtraction:", subtraction)
print("Multiplication:", multiplication)
```

Example:

```text
Enter first number: 10
Enter second number: 5

Addition: 15
Subtraction: 5
Multiplication: 50
```
