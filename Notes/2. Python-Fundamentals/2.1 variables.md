#  What Is a Variable?
- A **variables** help us store information and use it later.
- A **variable** is a name used to store a value.

Here:

```python
name = "Saravanan"
```

Think about a box.

```text
name
┌──────────────┐
│   Saravanan  │
└──────────────┘
```



* `name` → variable
* `"Saravanan"` → value
* `=` → assignment operator

### Example

```python
name = "John"
age = 25
```

We created two variables:

```text
name → John
age  → 25
```

### Print the values

```python
name = "John"
age = 25

print(name)
print(age)
```

Output:

```text
John
25
```

#  Why Do We Need Variables?


### Example

Imagine a student application.

We need to store:

```text
Student Name
Student Age
Student Course
Student Mark
```

We can use variables:

```python
student_name = "Arun"
student_age = 22
student_course = "Generative AI"
student_mark = 85
```

Then:

```python
print(student_name)
print(student_age)
print(student_course)
print(student_mark)
```

Output:

```text
Arun
22
Generative AI
85
```
