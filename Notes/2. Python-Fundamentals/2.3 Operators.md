#  Basic Operators

Operators are symbols used to perform operations.

Python provides many operators.
| Category       | Operators                  | Purpose                                              |
| -------------- | -------------------------- | ---------------------------------------------------- |
| **Arithmetic** | `+ - * / % // **`          | Mathematical calculations                            |
| **Comparison** | `== != > < >= <=`          | Compare two values                                   |
| **Assignment** | `= += -= *= /= %= //= **=` | Assign/update values                                 |
| **Logical**    | `and or not`               | Combine conditions                                   |
| **Membership** | `in`, `not in`             | Check whether a value exists                         |
| **Identity**   | `is`, `is not`             | Check whether two variables refer to the same object |


In this lesson:


| Operator | Name           | Example   | Result |
| -------- | -------------- | --------- | -----: |
| `+`      | Addition       | `10 + 5`  |   `15` |
| `-`      | Subtraction    | `10 - 5`  |    `5` |
| `*`      | Multiplication | `10 * 5`  |   `50` |
| `/`      | Division       | `10 / 5`  |  `2.0` |
| `%`      | Remainder      | `10 % 3`  |    `1` |
| `//`     | Floor Division | `10 // 3` |    `3` |
| `**`     | Power          | `2 ** 3`  |    `8` |

---

# 1. Addition `+`

The `+` operator is used for addition.

```python
a = 10
b = 5

result = a + b

print(result)
```

Output:

```text
15
```

### Real-world example

```python
price = 100
delivery = 20

total = price + delivery

print(total)
```

Output:

```text
120
```

---

# 2. Subtraction `-`

The `-` operator subtracts one value from another.

```python
a = 10
b = 5

result = a - b

print(result)
```

Output:

```text
5
```

### Example

```python
salary = 50000
expense = 15000

balance = salary - expense

print(balance)
```

Output:

```text
35000
```

---

# 3.  Multiplication `*`

The `*` operator is used for multiplication.

```python
price = 100
quantity = 5

total = price * quantity

print(total)
```

Output:

```text
500
```

---

# 4. Division `/`

The `/` operator is used for division.

```python
total = 100
students = 4

result = total / students

print(result)
```

Output:

```text
25.0
```

### Important

Normal division `/` usually returns a **float**.

```python
print(10 / 2)
```

Output:

```text
5.0
```

---

# 5. Modulus `%`

The `%` operator returns the **remainder**.

### Example

```python
result = 10 % 3

print(result)
```

Output:

```text
1
```

Why?

```text
10 ÷ 3

3 × 3 = 9
10 - 9 = 1

Remainder = 1
```

### Real-world Example

The modulus operator is often useful for checking whether a number is even or odd.

```python
number = 10

print(number % 2)
```

Output:

```text
0
```

If the remainder is `0`, the number is even.

---

# 6. Floor Division `//`

The `//` operator performs division and removes the decimal part.

### Example

```python
result = 10 // 3

print(result)
```

Output:

```text
3
```

Normal division:

```python
print(10 / 3)
```

Output:

```text
3.3333333333333335
```

Floor division:

```python
print(10 // 3)
```

Output:

```text
3
```

### Easy Difference

```text
/   → Normal division
//  → Floor division
```

---

# 7. Power `**`

The `**` operator is used to calculate a power.

### Example

```python
result = 2 ** 3

print(result)
```

Output:

```text
8
```

Because:

```text
2 × 2 × 2 = 8
```

Another example:

```python
result = 5 ** 2

print(result)
```

Output:

```text
25
```

Because:

```text
5 × 5 = 25
```
