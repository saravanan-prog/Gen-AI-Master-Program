# What is AI

 **Artificial Intelligence** (AI) is a technology 
- that enables `computers to perform tasks` 
- that normally require **human intelligence**.

 #### `Examples`:
* Understanding text
* Recognizing images
* Understanding speech
* Making predictions
* Making decisions
* Solving problems

| Traditional AI                | Generative AI                   |
| ----------------------------- | ------------------------------- |
| Mainly predicts or classifies | Creates new content             |
| Spam detection                | Writes an email                 |
| Fraud detection               | Generates a report              |
| Face recognition              | Generates an image              |
| Disease prediction            | Creates a medical summary       |
| Recommendation systems        | Generates a product description |

# Generative AI
**Generative AI** is a type of AI that can create new content.

It can generate:

* Text
* Images
* Audio
* Video
* Code

### Simple Example

If we ask an AI:

> "Write a Java program to find the largest number in an array."

The AI generates new code.
