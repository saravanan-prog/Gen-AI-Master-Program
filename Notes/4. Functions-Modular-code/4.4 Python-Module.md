# Python Module
A module is a Python file containing reusable code.

```
    project/
    │
    ├── calculator.py
    └── main.py

```

For example:  **calculator.py**

```
def add(a, b):
    return a + b
```



# Importing a Module

main.py:
```
    import calculator

    result = calculator.add(10, 20)

    print(result)

```
