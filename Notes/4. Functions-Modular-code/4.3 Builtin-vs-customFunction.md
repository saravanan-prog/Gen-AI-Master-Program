# 1. Built-in Functions

 Built-in functions are functions already `provided by Python`.
 We don't need to create them.

| Function  | Purpose             |
| --------- | ------------------- |
| `print()` | Display output      |
| `len()`   | Find length         |
| `type()`  | Find data type      |
| `sum()`   | Add numbers         |
| `max()`   | Find largest value  |
| `min()`   | Find smallest value |
| `input()` | Get input from user |
| `str()`   | Convert to string   |
| `int()`   | Convert to integer  |

### Example:
```
numbers = [10, 20, 30, 40]

print(len(numbers))
print(sum(numbers))
print(max(numbers))
```



# 2. Custom Functions

**Custom function**  A function `created by us`.
We use the `def` keyword.

```
def greet():
    print("Hello Students")

greet()

```
