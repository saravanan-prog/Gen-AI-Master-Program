#  Function Parameters

- Sometimes we want to give data to a function.
- That data is called a **parameter**.

Example:

```python
def say_hello(name):                         name → parameter
    print("Hello", name)

say_hello("Arun")                            Arun → argument
```

```text
Arun
```


### Function with Two Parameters

A function can have multiple parameters.

```python
def add(a, b):
    print(a + b)

add(10, 20)
```

Output:

```text
30
```

### Return Value

- Sometimes we don't want the function to directly print the result.
- We want the function to **give the result back**.
- For this, we use `return`.

Example:

```python
def add(a, b):
    return a + b

result = add(10, 20)

print(result)
```

Output:

```text
30
```
