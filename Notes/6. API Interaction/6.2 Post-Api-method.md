
# POST Using requests

Suppose we want to create a new student.

```
         Python
            |
            | POST
            | name = Arun
            | age = 22
            | course = Python
            ↓
        API Server
            |
            ↓
        Response

```





```
import requests

url = "https://jsonplaceholder.typicode.com/users"

student = {
    "name": "Arun",
    "age": 22,
    "course": "Python"
}

response = requests.post(url, json=student)

print(response.status_code)
print(response.json())
```
