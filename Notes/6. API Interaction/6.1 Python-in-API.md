# API
- **API** means Application Programming Interface.
- An API allows one application to `communicate` with another `application`.


Examples:

- Weather API
- Payment API
- Google Maps API
- GitHub API
- AI API

### Python requests Library

Install it:
```
    pip install requests
```

Python:
```
    import requests

    endPointURL = "https://jsonplaceholder.typicode.com/users"

    response = requests.get(endPointURL)
    data = response.json()
    print(data)

```

## Sending Parameters

```
import requests

url = "https://jsonplaceholder.typicode.com/users"

params = {
    "id": 1
}

response = requests.get(url, params=params)

print(response.url)
print(response.json())
```
