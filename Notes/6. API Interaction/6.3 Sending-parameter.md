## Sending Parameters

- Parameters help us request specific information from an API.

- **For example**, a student API may allow us to search for a student using an ID.


We will use a test API for this practical example.
```
    import requests

    url = "https://jsonplaceholder.typicode.com/users"

    params = {
        "id": 1
    }

    response = requests.get(url, params=params)

    print(response.url)
    print(response.json())
```
