# Python API PUT method
  We can use PUT to update the data.
```
  Existing data
     ↓
    PUT
     ↓
Updated data
```
Example
```

    import requests

    url = "https://jsonplaceholder.typicode.com/users/1"

    student = {
        "name": "Arun",
        "age": 22,
        "course": "AI"
    }

    response = requests.put(url, json=student)

    print("Status:", response.status_code)

    data = response.json()

    print(data)

```
