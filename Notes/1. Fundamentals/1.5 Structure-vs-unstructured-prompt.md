#  Structured vs Unstructured Prompts

## Unstructured Prompt

``` text
Tell me about Python and explain Function and give examples and make it easy.
```

The request is understandable, but the requirements are mixed together.

## Structured Prompt

``` text
Role:
You are a Python trainer.

Task:
Explain Python OpenAI.

Audience:
Beginners.

Topics:
- What is a OpenAi?
- Client connect
- Api Response

Requirements:
- Use simple English.
- Give one code example for each Hook.
- Explain the code line by line.

Output:
Use headings and code blocks.
```

### Key Difference

``` text
Unstructured → Natural request

Structured → Clearly organized instructions
```

Structured prompts are especially useful for:

-   Training
-   Business workflows
-   Repeated tasks
-   Automation
-   API-based applications
