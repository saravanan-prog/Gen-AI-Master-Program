

## Model Context Protocol (MCP)

 **MCP** is a standard way for an AI application to connect with `external tools`, databases, APIs, and other data sources.

 The external tool can be:
```
      Calculator
      Database
      API
      File
      Other software
```

In simple words:

```text
MCP = A standard connection between AI and external tools
```

### Why do we need MCP?

- An **AI** model can `generate text` and `answer questions`,
-  but it may need `external systems` to get `current information` or perform actions.

For example:

```text
                  AI
                  ↓
            "I need current customer information."
                  ↓
            Customer Database
```

The AI needs a way to communicate with that database.

MCP provides a standard approach for this type of connection.
