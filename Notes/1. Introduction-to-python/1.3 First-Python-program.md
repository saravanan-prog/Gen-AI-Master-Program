
# Create Our First Python File

Create a file called:

```text
hello.py
```

Add the following code:

```python
print("Hello, I am learning Python")
print("I want to learn Generative AI")
```

Run the program:

```bash
python hello.py
```

Output:

```text
Hello, I am learning Python
I want to learn Generative AI
```

## How Python Works

```text
hello.py
   ↓
Python Interpreter
   ↓
Execute Python Code
   ↓
Output
```

### Simple Explanation

* We write Python code in a `.py` file.
* The Python interpreter reads the code.
* Python executes the code.
* We see the result as output.
