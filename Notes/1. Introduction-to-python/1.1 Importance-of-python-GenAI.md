# Python of GenAI

Python is a programming language. It is very popular in:

* Artificial Intelligence (AI)
* Machine Learning (ML)
* Generative AI
* Data Science

Python is easy to learn and has many useful libraries for AI.

## Simple Flow

```text
    Python
      ↓
    AI Libraries
      ↓
    OpenAI / Ollama / Hugging Face
      ↓
    Generative AI Application
```

## Real-World Example

Suppose we want to create a simple AI chatbot.

```text
    User
      ↓
    Python Program
      ↓
    AI Model
      ↓
    Response
      ↓
    User
```

Python can be used to connect our application with an AI model.
