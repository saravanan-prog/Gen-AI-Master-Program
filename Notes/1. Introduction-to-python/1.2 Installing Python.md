# Installing Python

#### Step 1 : Check Whether Python Is Installed
```
Step1:  Open **Command Prompt** or **PowerShell**.

Step2: Run: python --version


Example output: Python 3.13.5

```
#### Step 2:
PIP is a tool used to install ***Python packages/libraries***.

```
    python -m pip --version

    Example output: pip 26.1.2 
```

If Python is installed, we can start writing Python programs.
