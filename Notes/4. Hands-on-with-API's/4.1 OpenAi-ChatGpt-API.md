## OpenAI ChatGPT API

- ***Example***: Python sends a question and receives an AI-generated answer.


```     
     USER PROMPT
          |

      AI MODEL
```

### What is ChatGPT API
ChatGPT API allows developers to use OpenAI models inside their own applications.
For example:
- Website chatbot.
- Email generator.
- Resume assistant.
- Customer support application.
- AI learning assistant.

## Embeddings
- Embeddings convert text into a list of numbers called vectors.
- These numbers represent the meaning of the text.
```
Sentence 1: I love Python programming.

Sentence 2: I like learning Python.

Sentence 3: I love eating pizza.
````

```
Sentence 1:
[0.25, 0.80, 0.45, 0.12]

Sentence 2:
[0.27, 0.78, 0.48, 0.15]

Sentence 3:
[0.90, 0.10, 0.20, 0.75]

```
