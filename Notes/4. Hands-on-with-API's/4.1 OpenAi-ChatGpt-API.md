## OpenAI ChatGPT API
- OpenAI API connects our Python application with OpenAI AI models.
- ***Example***: Python sends a question and receives an AI-generated answer.


```     
     USER PROMPT
          |
          v
      AI MODEL
          |
          v
   TEXT GENERATION
          |
          v
    AI RESPONSE

```
### What is ChatGPT API
ChatGPT API allows developers to use OpenAI models inside their own applications.
For example:
- Website chatbot.
- Email generator.
- Resume assistant.
- Customer support application.
- AI learning assistant.

## Text Generation
Text generation means creating new text based on the user's input

```
User Prompt
     |
     v
  AI Model
     |
     v
Generated Text

```
### Step 1: Install package.
```
pip install openai
```
### Step 2 : Set API key in PowerShell.
```
$env:OPENAI_API_KEY="your_api_key"
```
### Step 3: Create text_generation.py
```
from openai import OpenAI

client = OpenAI()

response = client.responses.create(
    model="gpt-4.1-mini",
    input="Explain Python"
)

print(response.output_text)
```



## Embeddings
- Embeddings convert text into a list of numbers called vectors.
- These numbers represent the meaning of the text.
```
Sentence 1: I love Python programming.

Sentence 2: I like learning Python.

Sentence 3: I love eating pizza.
````

```
Sentence 1:
[0.25, 0.80, 0.45, 0.12]

Sentence 2:
[0.27, 0.78, 0.48, 0.15]

Sentence 3:
[0.90, 0.10, 0.20, 0.75]

```

```
from openai import OpenAI

client = OpenAI()

response = client.embeddings.create(
    model="text-embedding-3-small",
    input="I love Python"
)

result = response.data[0].embedding

print(result[:5])
```
