### Tokens

A Token is a small piece of text that an AI model reads and understands. A token can be a word, part of a word, or punctuation.


Simple example : 

> I love learning GenAI

```
Input Sentence
      |
      v
 I love learning GenAI
      |
      v
  Tokens
      |
      v
 [I] [love] [learning] [Gen] [AI]


```

### Lab Program 1 – Count Tokens

Objective: Understand how text is converted into tokens.

Install Python package:

> pip install tiktoken

```

    import tiktoken

    text = "I love learning Generative AI"

    encoding = tiktoken.get_encoding("cl100k_base")

    tokens = encoding.encode(text)

    print("Input Text:", text)
    print("Tokens:", tokens)
    print("Token Count:", len(tokens))

```
