#  Embedding ?
 > An embedding converts text into numbers so a computer can compare the meaning of text.

Example:
```
    "How can I borrow a book?"
```
An embedding model converts it into numbers:
```
[0.21, -0.45, 0.78, 0.12, ...]
```
These numbers are called a vector.

### Simple Flow
```
    Text
     ↓
 Embedding Model
     ↓
   Numbers
     ↓
   Vector
```

```
Document
"The library is open from 9 AM to 6 PM."
             ↓
        Embedding Model
             ↓
       [0.21, 0.45, ...]


Question
"When can I visit the library?"
             ↓
        Embedding Model
             ↓
       [0.20, 0.47, ...]
```
