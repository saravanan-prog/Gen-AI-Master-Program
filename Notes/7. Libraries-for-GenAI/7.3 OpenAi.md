
## GenAI API Model

- GenAI means **Generative Artificial Intelligence**.
- API means **Application Programming Interface**.
- A GenAI API helps ***our application communicate*** with an ***AI model***.
- We send a question to the AI model and get an answer.

## OpenAi
This library helps Python communicate with OpenAI APIs.

### You need three things:

**API Key**: A secret key to access the AI service.
```
Step 1: Open OpenAI Platform
Go to the official website: https://platform.openai.com/api-keys?utm_source=chatgpt.com

Step 2: Sign in
- Login using your OpenAI account.
- Complete verification if requested.

Step 3: Create API Key

1. Click Create new secret key.
2. Give your key a name (example: Python-GenAI).
3. Click Create secret key.
4. Copy the key immediately and save it safely.

```

**Model**: The AI model you want to use.

**Prompt**: The question or instruction you send to the model.
API Key


### Step 1: Install package.
```
pip install openai
```
### Step 2 : Set API key in PowerShell.
```
$env:OPENAI_API_KEY="your_api_key"
```
### Step 3: Create text_generation.py
```
from openai import OpenAI

client = OpenAI()

response = client.responses.create(
    model="gpt-4.1-mini",
    input="Explain Python"
)

print(response.output_text)
```


### Step 3: Run the application
```
    python app.py
```

### Hands-on Example 2: Ask different questions

We can change the prompt without changing the API code.

```
question = "Explain Artificial Intelligence"

response = client.responses.create(
    model="gpt-4.1-mini",
    input=question
)

print(response.output_text)
```


### Hands-on Example 3: Build a simple chatbot

A chatbot accepts questions from users and sends them to the AI model.

```
from openai import OpenAI

client = OpenAI()

while True:

    question = input("You: ")

    if question == "exit":
        break

    response = client.responses.create(
        model="gpt-4.1-mini",
        input=question
    )

    print("AI:", response.output_text)
```
