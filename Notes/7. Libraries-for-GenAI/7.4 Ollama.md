
## Ollama
- **Ollama is a tool** for running AI models locally.
- You can **download models** and run them on your computer.
- It provides an API to **communicate with AI models**.
- You can use Python to call the Ollama API.

### Call Ollama API using Python

```
pip install ollama
```
ollama_demo.py
```
from ollama import chat

response = chat(
    model="llama3.2",
    messages=[
        {
            "role": "user",
            "content": "What is Python?"
            "stream": False
        }
    ]
)

print(response.message.content)
```

### Hands-on Example 3: Summarize text

```
from ollama import chat

text = """
Artificial Intelligence helps machines
perform tasks that normally require
human intelligence.
"""

response = chat(
    model="llama3.2",
    messages=[
        {
            "role": "user",
            "content": "Summarize this text: " + text
        }
    ]
)

print(response.message.content)

```

### Example program
```
import requests

url = "http://localhost:11434/api/generate"

data = {
    "model": "llama3.2",
    "prompt": "Explain Java in simple words",
    "stream": False
}

response = requests.post(url, json=data)

print(response.json()["response"])
```
