## NumPy (Numerical Python)

**NumPy** is a **Python library** used to perform `mathematical` and `numerical` operations on large amounts of data.

### Why is NumPy important for Generative AI?

- Handles numerical data efficiently.
- Performs matrix and array operations.
- Supports vector and matrix calculations.
- Helps understand embeddings.
- Supports mathematical operations used in Machine Learning and Deep Learning.

### Installation:

> pip install numpy

### Example 1: Creating an Array

```
import numpy as np

numbers = np.array([10, 20, 30, 40])

print(numbers)

Output :

[10 20 30 40]

```


### Example 2: Mathematical Operations

```
import numpy as np

numbers = np.array([10, 20, 30])

print(numbers + 5)
print(numbers * 2)


Output:

 [15 25 35]
 [20 40 60] 

```


### Example 3: Matrix Operations

```
import numpy as np

matrix = np.array([
    [1, 2],
    [3, 4]
])

print(matrix)
print(matrix.shape)

Output:

 [ [1 2]
   [3 4] ]



(2, 2)

```
