## What is Pandas

**Pandas** is an important **Python library** used to read, process, clean, filter, and analyze data.

In GenAI applications, Pandas helps us **prepare data before sending it to an AI model** or storing it in a vector database like **ChromaDB**.

Pandas is a **Python library** used to work with **structured data** in `rows` and `columns`.

```
1	Arun	Python	85  
2	Ravi	Java	90
3	Priya	GenAI	95

```

#### 1. Series

A Series is a single-dimensional collection of data.

```
import pandas as pd

marks = pd.Series([85, 90, 95])

print(marks)

```

#### 2. DataFrame

A DataFrame is a table with rows and columns.

```
import pandas as pd


data = {
    "Name": ["Arun", "Ravi", "Priya"],
    "Marks": [85, 90, 95]
}

df = pd.DataFrame(data)

print(df)

```


#### 3. Read CSV File

```
import pandas as pd


df = pd.read_csv("students.csv")

print(df)
```


#### 4. Read Excel File
```
import pandas as pd

df = pd.read_excel("students.xlsx")

print(df)
```

### 5. View Dataset
```
import pandas as pd

df = pd.read_excel("students.xlsx")

print(df.head())
print(df.tail())
print(df.shape)
print(df.columns)
print(df.info())
print(df.describe())
```

### 6. Select Columns

```
    import pandas as pd

    df = pd.read_excel("students.xlsx")

    print(df["Name"])
    print(df[["Name", "Marks"]])

```
#### 7. Filter Data

```

    import pandas as pd

    df = pd.read_excel("students.xlsx")

    result = df[df["Marks"] > 85]

    print(result)

```

### 9. Remove Duplicate Data

```
import pandas as pd

df = pd.read_excel("students.xlsx")

df = df.drop_duplicates()
```

### 10. Add New Column

```
df["Status"] = "Pass"
```
