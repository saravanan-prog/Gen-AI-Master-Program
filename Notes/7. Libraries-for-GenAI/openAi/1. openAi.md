### Simple example

```
from openai import OpenAI                      ---->  Imports the OpenAI class from the library.

client = OpenAI(api_key="YOUR_API_KEY")        ---->  Creates a connection to the OpenAI API.

response = client.responses.create(
    model="YOUR_MODEL",
    input="Explain AI in simple English"       ---->  Sends our prompt to the model.
)

print(response.output_text)                     ---->  Prints the AI's answer.

```
