
## Major Model Families

A model family is a group of AI models designed to perform different tasks such as text generation, coding, reasoning and image understanding.

```
          AI MODEL FAMILIES
                 |
    +------------+------------+
    |            |            |
   GPT         Gemini       LLaMA
    |            |            |
 Reasoning    Multimodal    Local AI
    |
    +------------+------------+
                 |
           +-----+-----+
           |           |
         Claude      Mistral
           |           |
        Documents   Efficiency

```

| Model Family | Developed By | Main Strength              |
| ------------ | ------------ | -------------------------- |
| GPT          | OpenAI       | Reasoning and Coding       |
| Gemini       | Google       | Multimodal Processing      |
| LLaMA        | Meta         | Local AI Development       |
| Claude       | Anthropic    | Long Documents and Writing |
| Mistral      | Mistral AI   | Efficient AI Models        |


### Strengths vs Limitations

| Model   | Strengths                 | Limitations                              |
| ------- | ------------------------- | ---------------------------------------- |
| GPT     | Reasoning, Coding         | Hallucination                            |
| Gemini  | Text, Image, Audio, Video | Quality varies                           |
| LLaMA   | Local Deployment          | Hardware required                        |
| Claude  | Document Analysis         | Usage limits                             |
| Mistral | Efficiency                | Smaller models may have weaker reasoning |

```
ollama pull llama3.2

```

```
import ollama

models = ["llama3.2", "mistral"]

for model in models:

    response = ollama.generate(
        model=model,
        prompt="Explain Artificial Intelligence in simple English"
    )

    print("\nModel:", model)
    print(response["response"])
```
