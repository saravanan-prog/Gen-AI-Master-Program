## 1. Context Window Length

A **Context Window** is the maximum number of tokens an AI model can process in a single request, including relevant input and generated output.

##  Simple explanation


- Imagine you are reading a book.
- You can remember and understand only a limited amount of information at one time.
- Similarly, an AI model has a context window limit.

For example:
```
    Model context window = 10,000 tokens.
    Your conversation uses 2,000 tokens.
    Remaining capacity = 8,000 tokens.
```


##  Lab Program – Context Window Calculation

```
context_window = 10000

input_tokens = 2000

output_tokens = 1000

used_tokens = input_tokens + output_tokens

remaining_tokens = context_window - used_tokens

print("Context Window:", context_window)
print("Input Tokens:", input_tokens)
print("Output Tokens:", output_tokens)
print("Used Tokens:", used_tokens)
print("Remaining Tokens:", remaining_tokens)

```

## 2. Inference Latency

**Inference Latency** is the time an AI model takes to process your request and generate a response.

It is usually measured in **milliseconds** or **seconds**.

#### Why is latency important

- Faster answers improve user experience.
- Slow responses make users wait.
- Important for chatbots and real-time applications.
-Helps businesses build faster AI applications.

## Lab Program

```
import time

start_time = time.time()

# Simulate AI processing
time.sleep(2)

print("AI Response Generated")

end_time = time.time()

latency = end_time - start_time

print("Inference Latency:", latency, "seconds")

```

## 3.  model scale

- Model scale refers to the ***size of an AI model***. It is usually measured by the ***number of parameters inside the model***.

- ***Parameters*** are values (numbers) that an AI model learns during training.

- These values help the model identify patterns and generate answers.

***Simple example:***

| Model   | Total Parameters | Size   |
| ------- | ---------------- | ------ |
| Model A | 1 Billion        | Small  |
| Model B | 7 Billion        | Medium |
| Model C | 70 Billion       | Large  |
