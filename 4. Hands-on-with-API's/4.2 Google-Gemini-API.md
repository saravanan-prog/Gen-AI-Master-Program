## Google Gemini API – Multimodal Processing

***Google Gemini API***: An API used to connect Python applications with Google's Gemini AI models.

***Multimodal Processing***: Processing different types of data such as text, images, audio and video.

***API Key:*** A secret key used to connect our application with Gemini.

```
   Python Application
          |
     Gemini API
          |
   ----------------
   |   |    |     |
  Text Image Audio Video
   |   |    |     |
   ----------------
          |
      Gemini AI
          |
    AI Response
```
### Python Setup
```
pip install google-genai
```
### Set API key in PowerShell:

Before u need to get the API_Key : https://aistudio.google.com/onboarding

```
$env:GEMINI_API_KEY="YOUR_API_KEY"
```
### Important Python Code – Text Generation
```
from google import genai

client = genai.Client()

response = client.models.generate_content(
    model="gemini-flash-latest",
    contents="Explain how AI works in a few words",
)

print(response.text)
```
