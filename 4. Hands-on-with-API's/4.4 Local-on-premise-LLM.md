## Local LLM
A Local LLM is an AI model that runs on our own computer instead of using an online AI service.

- ***LLaMA*** – Developed by Meta.
- ***Mistral*** – Developed by Mistral AI.

### What is On-Premise LLM

- On-premise means running an AI model on our own computer or company server instead of a cloud server.

- ***Example:*** A company runs an AI chatbot on its own server to process internal company documents.

### Important Tools
| Tool    | Purpose                       |
| ------- | ----------------------------- |
| Ollama  | Runs LLMs locally             |
| LLaMA   | AI model from Meta            |
| Mistral | AI model from Mistral AI      |
| Python  | Connects to local LLM         |
| VS Code | Used to write Python programs |

### Download LLaMA:

```
    ollama pull llama3.2
    ollama run llama3.2
```
### Download Mistral:
```
ollama pull mistral
ollama run mistral
```

###  Advantages
- Data privacy.
- No paid API credits for local inference.
- Works offline after downloading models.
- More control over AI models.
