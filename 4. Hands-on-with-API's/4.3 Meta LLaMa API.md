## Meta LLaMA API

LLaMA is an AI model developed by Meta. It understands user questions and generates answers.
### Important Concepts

- ***LLaMA:*** Meta's Large Language Model.
- ***Open-weight:*** Model weights are available to download under its licence.
- ***API:*** Used to communicate with the AI model.
- ***Ollama:*** Tool used to run LLaMA locally.
- ***Customization:*** Changing AI behaviour using instructions.
- ***Fine-tuning:*** Adapting a model using training data.
- ***Inference:*** Generating answers using a trained model.

## How to use LLaMA

- ***Meta LLaMA API:*** Use Meta's hosted API with an API key.
- ***Local LLaMA:*** Run a LLaMA model on your computer using Ollama.

### Practical Commands
```
ollama pull llama3.2
ollama run llama3.2
```

```
import requests

url = "http://localhost:11434/api/generate"

data = {
    "model": "llama3.2",
    "prompt": "Explain Python",
    "stream": False
}

response = requests.post(url, json=data)

print(response.json()["response"])
```
