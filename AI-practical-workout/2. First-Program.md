
# Create : **first_ollama.py**

Put:
```
    import ollama

    response = ollama.chat(
        model="llama3.2",
        messages=[
            {
                "role": "user",
                "content": "What is Generative AI?"
            }
        ]
    )

    print(response["message"]["content"])

```

Program Run : **python first_ollama.py**



### Explaintaiton 
```
import ollama     -> Bring the Ollama Python library into our program.

ollama.chat(...)  ->  Send a chat request to an AI model.

model="llama3.2"  ->  Use the Llama 3.2 model.

content=
"What is Generative AI?"   ->This is our prompt.

```
