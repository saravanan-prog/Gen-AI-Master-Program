## On-Premise vs Cloud

#### On-Premise:
- Bank installs LLaMA on its own server.
- Customer data is processed on that server.
- Bank manages the server.
#### Cloud:
- Bank uses an online AI API.
- Questions are sent to the cloud service.
- Cloud provider runs the AI model.

## On-Premise Deployment

Running an AI model on our own computer or company's own server instead of using an external cloud server.

***Example:*** A bank installs an AI chatbot on its own company server.

```
User
  |
  v
Company Server
  |
  v
LLM Model
  |
  v
AI Response
```

## Cloud Deployment

Running an AI model on an online cloud server and accessing it through the internet.

***Example:*** Using ChatGPT through the internet.
