### Trade-offs

Trade-offs mean comparing the advantages and disadvantages before choosing something.

***Example:*** Local LLM gives more data control but needs a powerful computer.


### Hardware Considerations

Hardware considerations mean checking whether our computer has enough resources to run an AI model.

| Hardware | Purpose                        |
| -------- | ------------------------------ |
| CPU      | Processes instructions         |
| GPU      | Speeds up AI processing        |
| RAM      | Holds model data while running |
| VRAM     | GPU memory                     |
| Storage  | Stores AI models               |

### Cost Factors

Cost factors are the expenses required to run and maintain an AI application.

| On-Premise Cost   | Cloud Cost           |
| ----------------- | -------------------- |
| Server purchase   | API charges          |
| GPU purchase      | Cloud GPU charges    |
| Electricity       | Cloud computing      |
| Maintenance       | Storage charges      |
| Hardware upgrades | Subscription charges |
